# Pygame Racing – GA-ready prototype

키보드로 먼저 주행해 볼 수 있고, 이후 유전 알고리즘 에이전트를 연결하기 쉽게
구성한 2D 레이싱 프로토타입입니다.

## 실행

```bash
python3 main.py
```

시작 화면에서 `DIRECT DRIVE` 또는 `AI`를 선택합니다. AI를 선택하면 유전 알고리즘의
돌연변이율, 완주율·시간·충돌 횟수별 가중치, 개체수, 엘리트 수를 설정할 수 있습니다.
`Training track` 버튼으로 `Classic Split`, `River Run`, `Canyon Switchback` 중 학습할
트랙을 고를 수 있습니다. 새 트랙은 각각 시작선과 순서형 체크포인트를 독립적으로 가집니다.
AI 모드는 설정값으로 개체군을 생성해 30초 평가·10초 무진행 종료·엘리트 보존·교차·돌연변이를
반복합니다. 화면에는 현재 세대의 선두 차량만 표시됩니다.
기본 개체수는 100, 기본 엘리트 수는 10입니다.
AI 설정의 `Agent view`에서 선두 한 대만 표시하는 `BEST ONLY`와 모든 개체를 표시하는
`ALL AGENTS`를 전환할 수 있습니다. 전체 표시에서도 센서는 선두 개체에만 표시됩니다.
`Seed mode`에서 매 실행마다 새 시드를 만드는 `RANDOM` 또는 재현 가능한 `ENTER SEED`를
고를 수 있습니다. `Training speed`는 시뮬레이션 시간을 `1x / 4x / 16x / 64x`로 조절합니다.
`MAX`는 화면 반응성을 유지하는 범위에서 가능한 많은 학습 틱을 처리합니다. 최고 속도는
`BEST ONLY` 표시에서 가장 잘 나옵니다.
학습 개체의 센서는 성능을 위해 6픽셀 간격으로 탐색하되, 벽 근처에서는 보정합니다.

AI 학습 화면의 오른쪽 위 `☰` 버튼(또는 `M`)에서는 실험을 멈추지 않고 표시 방식과
학습 속도를 바꿀 수 있습니다. 여기의 `TEST: ...`는 현재 선두 AI의 유전자를 고정한 뒤
다음 트랙에서 단독 평가합니다. 이 동안 원래 학습은 일시 정지하며, 테스트 결과는 학습
개체군·적합도·CSV에 섞이지 않습니다. `BACK TO TRAINING` 또는 `T`로 정확히 그 시점의
학습으로 돌아갑니다. 따라서 다른 트랙에 대한 일반화 성능(과적합 여부)을 눈으로 확인할 수
있습니다. `RETURN TO MENU`는 현재 실행을 종료하고 시작 메뉴로 돌아갑니다. 새 AI 실험을
시작할 때마다 별도의 결과 폴더가 생성됩니다.

AI 학습 중 `P`를 누르면 대결 모드가 켜집니다. 선택된 AI 한 대만 해당 세대 동안 고정
표시되고, 노란색 플레이어 차량을 `WASD`/방향키로 조종할 수 있습니다. 대결 모드에서는
공정한 속도를 위해 AI 학습 표시가 1배속으로 동작하며, 플레이어 차량은 학습·적합도·CSV
결과에 포함되지 않습니다.

## 실험 결과 저장

AI 학습을 시작하면 프로젝트의 `results/` 폴더 안에 실험 조건·시드·시각으로 이름 붙은
결과 폴더가 자동으로 생성됩니다. 세대가 끝나는 즉시 두 CSV가 갱신되므로, 실행을 중간에
종료해도 이미 끝난 세대의 데이터는 남습니다.

- `summary.csv`: 세대별 최고/평균 적합도와 진행률, 완주 개체 수·완주율·가장 빠른 완주
  시간·평균 충돌 횟수, 최초 완주 세대와 최초 무충돌 완주 세대
- `individuals.csv`: 세대의 모든 개체별 순위, 적합도, 진행률, 완주 여부, 주행 시간,
  충돌 횟수, 체크포인트 통과 수

두 파일의 각 행에는 실험 ID, 학습 트랙, 시드, 돌연변이율, 적합도 가중치, 개체 수,
엘리트 수, 센서 각도와 종료 조건도 함께 저장됩니다. 시작 화면의 `VIEW RESULTS`에서
저장된 실험을 넘겨 보고, `DOWNLOAD SUMMARY` 또는 `DOWNLOAD INDIVIDUALS`를 누르면
각 CSV 사본이 `Downloads` 폴더로 복사됩니다.

- `↑ / W`: 가속
- `↓ / S`: 브레이크 / 후진
- `← → / A D`: 조향
- `R`: 시작 위치로 재시작
- `V`: 센서 표시 전환
- `Esc`: 종료

의존성이 없다면 `python3 -m pip install -r requirements.txt`로 설치합니다.

## 구조

- `racing/car.py`: 물리 상태와 `ControlInput` (키보드/AI 공용 입력)
- `racing/sensors.py`: 전방 5방향 거리 센서와 정규화 관측값
- `racing/track.py`: 선택 가능한 트랙 레이아웃, 경계, 체크포인트, 중앙선 데이터
- `racing/evaluation.py`: 평가 전략 인터페이스 및 체크포인트 평가기
- `racing/neural.py`: 유전자로 구성되는 `6 → 10 → 6 → 2` 신경망
- `racing/evolution.py`: 개체 평가, 선택, 교차, 돌연변이, 세대 교체
- `racing/ga_config.py`: 유전 알고리즘과 적합도 설정값 검증
- `racing/game.py`: Pygame 표시와 게임 루프

현재 평가는 순서가 있는 체크포인트 통과와 랩 완료를 사용합니다. 중앙선 기반 평가는
`ProgressEvaluator` 인터페이스의 다른 구현으로 추가할 수 있으며, 트랙은 이미 중앙선
샘플을 별도로 제공합니다. 이 덕분에 두 평가법을 차량/센서 코드 변경 없이 비교할 수
있습니다.

센서는 `-60°, -30°, 0°, 30°, 60°` 방향에서 인위적인 짧은 표시 제한 없이 실제
트랙 경계까지 측정합니다. 벽을 얕게 스치면 진행 방향을 유지하며 감속하고, 벽 표면
기준 45도 이상의 큰 각도로 충돌하면 짧은 역방향 반동으로 벽에서 떨어집니다.
충돌은 차량 꼭짓점만이 아니라 차체 전체를 덮는 7×5 표본으로 확인하고, 벗어난
부분이 없어질 때까지 차량 전체를 도로 안쪽으로 보정합니다.

트랙은 참고 이미지처럼 긴 상·하단 직선, 왼쪽의 2단 헤어핀, 오른쪽의 두 사선 경로로
구성됩니다. 사선 분기 사이에는 체크포인트가 없어 어느 쪽을 선택해도 정상적으로 랩
진행이 인정됩니다.
